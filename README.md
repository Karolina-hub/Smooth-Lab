# Smooth Lab — Лабораторная работа №1 (SPA)

## Описание проекта
Сайт студии эпиляции **Single Page Application (SPA)** на JavaScript. Все переходы между страницами происходят мгновенно без перезагрузки браузера.

## Технические характеристики
* **Стек:** HTML5, CSS3, Vanilla JavaScript (ES6+).
* **Роутинг:** Собственный Hash-router (отслеживание события `hashchange`).
* **Динамика:** Рендеринг контента из JS-объектов (имитация работы с API).
* **Стили:** Адаптивная верстка (Grid/Flexbox), использование CSS-переменных.

## Структура приложения (9 разделов)
1. **Главная (`/`)** — Презентация и переход к услугам.
2. **Каталог (`/catalog`)** — Динамический вывод карточек услуг.
3. **Детальная страница** — Подробное описание услуги с передачей ID в URL.
4. **Квиз-тест (`/quiz`)** — Интерактивный подбор процедуры.
5. **Поиск (`/search`)** — Интерфейс для поиска по базе услуг.
6. **Авторизация (`/auth`)** — Форма входа в кабинет.
7. **Личный профиль (`/profile`)** — Информация о пользователе и бонусах.
8. **Избранное (`/favorites`)** — Список сохраненных услуг.
9. **Админ-панель (`/admin`)** — Статистика посещений для персонала.
