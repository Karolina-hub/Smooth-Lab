# Динамическое веб-приложение "Smooth Lab"

Лабораторная работа №1 по курсу "Проектирование архитектуры динамических веб-приложений".

## 1. Концепция проекта
* **Название:** Smooth Lab — интерактивный сервис для студии лазерной эпиляции.
* **Описание:** Приложение позволяет пользователям ознакомиться с услугами студии, пройти интерактивный квиз для подбора индивидуальной программы и управлять списком избранных процедур.
* **Целевая аудитория:** Клиенты студий красоты, ценящие удобство онлайн-записи и персонализированный подход.
* **Ключевой функционал:** Динамическая навигация (SPA), фильтрация услуг, интерактивный тест (квиз), система управления избранным.

## 2. Технологический стек
* **Frontend:** Vanilla JavaScript (ES6+). *Обоснование:* использование чистого JS без тяжелых фреймворков позволяет продемонстрировать глубокое понимание DOM-дерева и маршрутизации.
* **Роутинг:** Hash-based SPA Router. *Обоснование:* обеспечивает мгновенную смену контента без перезагрузки страницы.
* **Backend (планируется):** Node.js (Express). *Обоснование:* высокая скорость разработки и единый язык (JS) для всего проекта.
* **База данных:** MongoDB. *Обоснование:* NoSQL база данных идеально подходит для хранения гибких моделей данных пользователей и услуг.
* **Хостинг:** GitHub Pages (Frontend).

| Раздел | Путь (Route) | Доступ | Описание |

## 4. Визуальное проектирование (Прототипы)

### Страница: Главная (#/)
* **Тип доступа:** публичный
* **Основные блоки:**
    1.  **Шапка:** Логотип "Smooth Lab", меню (Каталог, Квиз, Поиск), кнопка "Войти".
    2.  **Hero-блок:** Заголовок "Гладкость навсегда", кнопка перехода к Квизу.
    3.  **Секция "Популярное":** Сетка из карточек самых востребованных услуг (данные из JS-массива).
    4.  **Футер:** Соцсети, контакты, стек технологий.
* **Динамический контент:** Блок 3 (карточки подгружаются динамически).

### Страница: Каталог (#/catalog)
* **Тип доступа:** публичный
* **Основные блоки:**
    1.  **Сетка услуг:** Список карточек с ценами и кнопками "В избранное".
    2.  **Фильтры:** Быстрый выбор по зонам (лицо, тело, ноги).
* **Динамический контент:** Список услуг рендерится на основе массива данных.

## 5. Схема данных и API

### Модели данных
* **User:** `{ id, name, email, password, favorites: [] }`
* **Service:** `{ id, name, price, description, duration, image }`

### Ключевые эндпоинты API
* `POST /api/auth/login` — Аутентификация пользователя.
* `GET /api/services` — Получение полного списка услуг для каталога.
* `GET /api/services?popular=true` — Получение популярных услуг для главной.
* `GET /api/services/:id` — Получение детальной информации об услуге.
