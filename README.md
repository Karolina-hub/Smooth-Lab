# Smooth Lab — Студия эпиляции (SPA-приложение)

## Техническая реализация
* **Vanilla JavaScript (ES6+):** Вся логика, роутинг и рендеринг написаны на чистом языке.
* **Hash-based Routing:** Переключение между 9 разделами происходит через отслеживание `window.onhashchange`.
* **CSS3 (Grid & Flexbox):** Адаптивная верстка с использованием современных инструментов позиционирования и CSS-переменных для управления темой.
* **Dynamic Data:** Контент страниц (каталог, детали услуг) генерируется динамически из JavaScript-объектов.

## Структура сайта (9 разделов)
1. **Главная (`/`)** — Входная точка с описанием бренда.
2. **Каталог (`/catalog`)** — Сетка услуг с ценами и описанием.
3. **Детали услуги** — Страница с подробным разбором конкретной процедуры (динамический рендеринг по ID).
4. **Квиз (`/quiz`)** — Интерактивный опрос для выбора метода эпиляции.
5. **Поиск (`/search`)** — Поиск по базе данных услуг.
6. **Авторизация (`/auth`)** — Форма входа в кабинет.
7. **Личный профиль (`/profile`)** — Информация о клиенте и бонусной программе.
8. **Избранное (`/favorites`)** — Раздел для сохранения понравившихся услуг.
9. **Админ-панель (`/admin`)** — Технический раздел со статистикой записей.
